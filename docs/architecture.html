GENBOT — LLM-Powered Discord Bot Architecture

discord.js v14 · OpenAI-compatible LLM · AES-256-GCM encrypted per-guild secrets · Node.js ESM

Core Modules

  • index.js — event wiring, agent loop, intents
  • llm.js — SYSTEM_PROMPT, JSON plan parser, risk gates
  • actions.js — 50 executeAction handlers
  • store.js — encrypted guild config, memory, tasks
  • commands.js — 6 slash command groups

Security Model

  • AES-256-GCM via node:crypto scrypt-derived key
  • CONFIG_SECRET never leaves .env
  • Per-guild API keys encrypted at rest
  • Role tiers: botowner > serverowner > staff > member
  • Privileged action gate + confirmation prompts

Agent Loop

  • Single LLM call per step (JSON mode)
  • Up to 6 retry steps with ACTION RESULTS feedback
  • Confirmation dialog for risky plans
  • Server-side risk enforcement (belt-and-braces)
  • 50-action cap per plan

Persistence

  • Per-guild JSON config (welcome, bye, custom commands)
  • Conversation turns (20/channel rolling window)
  • Long-term notes (40/server, LLM-remembered facts)
  • tasks.json — schedules + giveaways survive restart
  • buttons.json — button interaction handlers
